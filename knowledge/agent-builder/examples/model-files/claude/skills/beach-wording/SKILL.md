# Beach wording

- Lead with the veto when one applies: "Rip current statement in effect - stay out of the water."
- Labels map to score bands from the `beach-day-score` skill; do not invent new bands.
- One idea per tip, under 90 characters, no exclamation marks for risk.
- Always end alert-related text with the not-an-official-warning notice from `risk-communication`.
